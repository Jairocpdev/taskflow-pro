# 🚀 TaskFlow Pro

> Um gerenciador moderno de tarefas desenvolvido com **HTML5, CSS3 e JavaScript**, focado em produtividade, organização e uma experiência de usuário elegante.

## 📖 Sobre o projeto

O **TaskFlow Pro** é uma aplicação web para gerenciamento de tarefas criada com foco em um código limpo, interface moderna e organização em módulos.

O objetivo do projeto é permitir que o usuário acompanhe suas atividades de maneira simples, rápida e intuitiva.

Este projeto foi desenvolvido para demonstrar conhecimentos em:

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- Manipulação do DOM
- Responsividade
- Organização de código

---

## ✨ Funcionalidades

- ✅ Criar tarefas
- ✅ Editar tarefas
- ✅ Excluir tarefas
- ✅ Concluir tarefas
- ✅ Persistência de dados com LocalStorage
- ✅ Dashboard com estatísticas
- ✅ Tema claro/escuro
- ✅ Interface moderna
- ✅ Layout responsivo
